# 好好说话 🗣️

> 一个萌新的第一个项目。

这是一个用 Python 写的「观点交流」小脚本。它想换一种方式和你聊天：抛出几条关于社交与自我认知的观点，请你回答「是」或「不是」，看看我们能不能好好说话、达成共识。

## 它做了什么

程序会一条条输出下面这些观点，并问你「是或不是」：

- 回答「是」→ 进入下一条观点；
- 回答「不是」→ 停下来，说「让我们就这个问题深入交流吧」；
- 全部回答「是」→ 最后说「太好了，我们达成了共识！」。

## 运行方式

需要 Python 3。在项目目录下执行：

```bash
python 测试二.py
```

## 这些观点

1. 人的精力是有限的，精力不足时就必须有所取舍；
2. 好的社交是让人舒服的，不需要一直表演、一直输出有意思的内容；
3. 好的社交里，双方都在表达、都在倾听；
4. 对自己认知越深，越能把握行为背后的原因；
5. 没参与讨论，但大家发的消息都看了。
